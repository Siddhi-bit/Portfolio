## Deploy in 60 Seconds

### Option 1 — Vercel (recommended)

1. Fork or upload this repo to GitHub
2. Go to [vercel.com](https://vercel.com) and sign in with GitHub
3. Click **New Project** and import the repo
4. Vercel auto-detects the HTML file — click **Deploy**
5. Your site is live at `your-name.vercel.app`

### Option 2 — GitHub Pages

1. Create a repo named `your-github-username.github.io`
2. Upload `index.html` to the root
3. Go to **Settings → Pages → Source → Deploy from branch (main)**
4. Your site is live at `your-github-username.github.io`

### Option 3 — Netlify (drag and drop)

1. Go to [netlify.com](https://netlify.com)
2. Drag and drop the `index.html` file onto the deploy zone
3. Done — instant live URL, no account required

## Customization

All content is in `index.html`. To update:

- **Name / tagline** → edit the `.hero` section
- **Experience** → update `.exp-item` blocks under `#experience`
- **Projects** → update `.proj-card` blocks under `#projects`
- **Skills** → update `.skill-tag` lists under `#skills`
- **Contact links** → update `href` values in the `#contact` section
- **Colors** → edit `--blue`, `--blue-mid`, `--blue-light` in `:root`
